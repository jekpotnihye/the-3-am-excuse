An entry for the [The 3 AM Excuse](https://make.fun/bounty/u-hazel-walrus-38-4764-the-3-am-excuse-c1017878)
competition on make.fun: one line, in the voice of a hardware wallet
refusing to sign a transaction at 3 AM, written by a program
to `/output/entry.txt`.

## The line

> At 3 AM, even my two-inch screen sees this signature ending in a frog-hat JPEG. No.

## Run it

```sh
node main.ts
```

`main.ts` checks the line is 1 to 200 characters, writes it to
`/output/entry.txt` (override with `OUTPUT_PATH`), and prints it.
